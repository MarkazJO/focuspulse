Lock & Home Screen Widget

Get real-time ticking countdowns on your Lock Screen and Home Screen via free Scriptable widgets.

1. Get Scriptable Download the free Scriptable app from the App Store. Open in App Store →
2. Copy Widget Script Tap below to copy the widget code to your clipboard.
3. Add in Scriptable Open Scriptable → tap + (top right) → paste the code → name it FocusPulse → tap Done.
4. Add Widget to Lock / Home Screen • Lock Screen: Long-press Lock Screen → Customize → Add Widget → Select Scriptable → Choose Rectangular or Inline → select FocusPulse.
• Home Screen: Long-press Home Screen → + → Select Scriptable → Choose Small or Medium → select FocusPulse.
